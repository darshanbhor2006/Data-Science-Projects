# 🛒 Supermarket Sales – Interactive EDA Dashboard

An **Interactive Exploratory Data Analysis (EDA) Dashboard** built using Python and Jupyter Notebook to analyze supermarket sales data and generate meaningful business insights through attractive KPI cards and interactive visualizations.

The project provides a **Power BI-inspired dashboard experience inside Jupyter Notebook** without requiring Power BI, Streamlit, or `app.py`.

---

## 📊 Project Overview

The objective of this project is to explore supermarket sales data, clean and prepare the dataset, identify important sales patterns, and present the findings through an interactive dashboard.

The dataset contains **8,523 records and 12 columns**, including information about products, product categories, outlets, outlet characteristics, pricing, visibility, and outlet-level sales.

### Dataset Features

| Column                      | Description                               |
| --------------------------- | ----------------------------------------- |
| `Item_Identifier`           | Unique identifier of the item             |
| `Item_Weight`               | Weight of the item                        |
| `Item_Fat_Content`          | Fat content category of the item          |
| `Item_Visibility`           | Visibility of the item in the outlet      |
| `Item_Type`                 | Category/type of the item                 |
| `Item_MRP`                  | Maximum Retail Price of the item          |
| `Outlet_Identifier`         | Unique outlet identifier                  |
| `Outlet_Establishment_Year` | Year the outlet was established           |
| `Outlet_Size`               | Size of the outlet                        |
| `Outlet_Location_Type`      | Location tier of the outlet               |
| `Outlet_Type`               | Type of outlet                            |
| `Item_Outlet_Sales`         | Sales generated by the item at the outlet |

These fields are present in the uploaded CSV dataset.

## 🧹 Data Cleaning & Preparation

The project performs several data preparation steps:

### 1. Remove Duplicate Records

Duplicate records are removed from the dataset.

### 2. Handle Missing Item Weight

Missing values in `Item_Weight` are replaced using the **median item weight**.

### 3. Handle Missing Outlet Size

Missing values in `Outlet_Size` are filled using the **mode** of the column.

### 4. Standardize Item Fat Content

Different representations are standardized:

```text
LF       → Low Fat
low fat  → Low Fat
reg      → Regular
```

After cleaning, the notebook checks the dataset for remaining missing values.
